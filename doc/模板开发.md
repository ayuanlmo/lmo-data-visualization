# 📄 模板开发与数据通信说明文档

> 👋 本文档详细介绍了如何开发模板、构建模板结构，以及模板与设计器、服务器之间的数据传递方式。欢迎查阅！

---

## 🚀 模板消息传递方式

### 🔄 与设计器交互

模板与设计器之间通过以下方式进行通信：

- 使用 `iframe` 嵌套
- 通过 `postMessage` 实现跨域通信

📌 **注意事项：**

- 模板开发阶段无需关心消息通信机制 ✅
- 合成阶段时，监听器不会生效 ❗

---

### ⚡ 与服务器通信

模板与服务器之间使用 `WebSocket` 进行实时通信。

💡 **关键行为：**

- 在合成过程中保持连接 🔁
- 若合成被中断，服务器会发送 `__ABORT_RENDER` 信号给模板
- 收到该信号后，模板应立即停止渲染并释放资源 🧹

---

📁 **模板文件夹路径：**

## 🛠️ 如何开发模板

### 1️⃣ 引入SDK

在 `index.ts` 中引入必要的模块和类型定义：

```typescript
// index.ts

import LmoTemplate, {ILMOTemplateImplementsMethods} from "../../scripts/template.js";
import {TConfigOtherConfigItemValueType, TOtherConfig, TThemeConfig} from "../../scripts/@types/template.js";
import Conf from './conf.js';
```

---

### 2️⃣ HTML 文件结构（可选）

这是一个标准的模板 HTML 结构示例：

```html
<!doctype html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, user-scalable=no, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0">
    <meta http-equiv="X-UA-Compatible" content="ie=edge">
    <title>MyTemplate</title>
    <!-- 必要的样式文件 -->
    <link rel="stylesheet" href="../../styles/animate.min.css">
    <link rel="stylesheet" href="../../styles/default.css">
</head>
<body>

<!-- 可选组件 -->
<div id="template">
    <div class="animated fadeInDown" id="main-title">
        <div class="text-value" contenteditable></div>
    </div>
    <div class="animated fadeInDown" id="sub-title">
        <div class="text-value" contenteditable></div>
    </div>
    <div class="animated fadeInDown" id="from-source">
        <div class="text-value" contenteditable></div>
    </div>
    <div id="logo"></div>
    <div id="app" style="width: 100vw;height: calc(100vh - 120px);user-select: none;margin-top: 120px;"></div>
</div>

<!-- 🎧 音频插入标记 -->
<!--__LMO_SERVER_AUDIO_RENDER_TAG-->

<!-- 可选第三方库 -->
<script src="../../scripts/echarts.min.js"></script>
<script src="../../scripts/d3.js"></script>

<!--必要库-->
<script src="../../scripts/interact.min.js"></script>

<!-- 入口文件 -->
<script src="./index.js" type="module"></script>
</body>
</html>
```

> `interact.min.js`是作用于模板的鼠标交互相关的库，它是必须的。

✅ **注意：**

- `<script>` 类型必须为 `module`
- `<!--__LMO_SERVER_AUDIO_RENDER_TAG-->` 是音频插入标记，建议保留
- 若没有自定义 `index.html`，服务器将自动套用通用模板

### 3️⃣ 编写模板类

创建一个继承 `LmoTemplate` 并实现接口 `ILMOTemplateImplementsMethods` 的类：

```typescript
class MyTemplate extends LmoTemplate implements ILMOTemplateImplementsMethods {
    constructor() {
        super(Conf);
    }

    public render(): void | Promise<void> {
        const {data} = this.conf;
        // 渲染逻辑...
    }

    public themeColorChange(config: TThemeConfig): void {
        // 主题变化处理...
    }

    public otherConfigChange(config: TOtherConfig): void {
        // 其他配置项变更处理...
    }
}

new MyTemplate();
```

> 👀 为了更好的处理`otherConfigChange`您可以使用`Proxy`实现，以更好利用ts。

```typescript

// 定义基础类型
interface IOtherConfigProxyHandlers {
    myValue: string;
}

type TOtherConfigProxyHandlers = {
    [k: keyof IOtherConfigProxyHandlers]: () => void;
}

const otherConfigProxyHandlers: TOtherConfigProxyHandlers = {
    myValue: () => {
        console.log('myValue值发生了变化');
    }
}

// 创建proxy

new Proxy(this.conf.otherConfig.values, {
    set: (target: {
        [key: string]: IOtherConfigProxyHandlers;

    }, key: keyof IOtherConfigProxyHandlers, value: never): boolean => {
        otherConfigProxyHandlers(key);

        return Reflect.set(target, key, value);
    }
})

```

---

### ⚠️ 模板注意事项

> - 您不应该在模板中进行任何的跳转请求，它会被拦截。
> - 您的模板不应该存在大量CPU密集型计算或者使用大量的RAM，这将可能导致崩溃页面而中断合成。

---

### 4️⃣ 模板文件命名规范

| 文件名           | 描述        |
|---------------|-----------|
| `index.html`  | 模板主页面（可选） |
| `index.ts`    | 模板入口文件    |
| `conf.ts`     | 模板配置文件    |
| `config.json` | 模板基本信息配置  |
| `data.json`   | 模板使用的数据源  |
| `cover.png`   | 静态封面图     |
| `cover.gif`   | 动态封面图     |

export const conf: ITemplateConfig = {

### 自定义配置项格式（TOtherConfig）

#### 方式一：顺序排列

```typescript
const configType1: TOtherConfig = {
    label: '其他配置',
    configs: [
        {
            label: '配置项1',
            key: 'config1',
            type: 'text',
            value: 'hello'
        }
    ],
    values: {
        config1: 'hello'
    }
};
```

#### 方式二：分组排列

```typescript
const configType2: TOtherConfig = {
    group: [
        {
            label: '分组1',
            configs: [
                {
                    label: '配置项1',
                    key: 'config1',
                    type: 'text',
                    value: 'hello'
                }
            ]
        }
    ],
    values: {
        config1: 'hello'
    }
};
```

📌 **提示：**

- 两种格式只能选择其一
- 当 `type` 为 `select` 时，必须提供 `options` 字段

```typescript
const select = {
    label: '配置项1',
    key: 'config1',
    type: 'select',
    value: 'val1',
    options:
        [
            {label: '选项1', value: 'val1'}
        ]
}
```

> 如您在非`select`组件中 使用了`options`，ts将抛出错误。

## 📊 数据文件 `data.json` 示例

```json
[
  [
    "2020-01-01",
    "2020-01-02"
  ],
  [
    "1",
    "100"
  ]

```

## 📦 模板基本信息文件 `config.json`

```json
{
  "name": "凹凸排名图",
  "description": "适用于同一类别的内部排名变化",
  "type": 1
}
```

| 字段            | 描述                      |
|---------------|-------------------------|
| `name`        | 模板名称                    |
| `description` | 模板功能描述                  |
| `type`        | 模板类型：1 表示内置模板，0 表示自定义模板 |
